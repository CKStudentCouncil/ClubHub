# 關於美術社
美術社無疑是建中中對美術抱持熱情的學生所聚之處，因為對美術抱持憧憬與夢想而聚集，進而有了這個社團的存在。
因為每個人的不同，筆觸、施力、技巧、創意而有個人的獨特，這也是美術社最令人迷人之處，即使使用同一支筆創作，也如不同人欣賞同一幅畫作有不同的感受一樣，往往不盡相同。
美術社提供各式繪圖技巧的教學，包括素描、水彩、壓克力、油彩、電繪。同時給予社員一個可以自由發揮、創作、精進美術能力的環境。

# 美術社適合誰
加入美術社重要的不是自己有多優異的繪畫經歷或技巧，而是有一顆願意為美術燃燒的心，只要你對美術有興趣，願意付出時間學習，不管你是從小學畫，還是只會畫火柴人，美術社的大門永遠為你敞開！

# 在美術社的學習
社團擁有強大的教學學長，從基礎技法到進階創作，毫無保留地手把手傳授，讓你迅速上手！美術教室的畫筆工具等都可使用，顏料、畫布等社團也會提供。
如果社團課的時間不足以盡興，中午時間也可以到美術教室繼續創做！

# 美術社小社課
除了學校規定的一堂社團課，每個星期還有一堂放學後的小社課，自由參加。

# 美術社校外活動
包括迎新及社團聯展，北一、松山、政附、板中、和平、內湖、景美、新莊、永平的美術社團都是我們的合作對象。下學期的社團聯展正是展現自己學習成果的時候！
