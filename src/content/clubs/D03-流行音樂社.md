# 流音的表演形式是什麼？
我們的表演核心在於「人聲」，例如：個人獨唱、雙人對唱及阿卡貝拉的演出。這與其他樂團形式的社團有很大的不同。當然我們也非常歡迎會樂器的學弟加入，自彈自唱也是可以的！ 

# 不會唱歌也可以加流音嗎？
絕對可以！在這一年的社團時光中，學長們會帶著大家共同進步。無論唱歌功力如何，我們都一視同仁！只要有熱忱我們都歡迎你的加入。

# 有跟友校交流的機會嗎？
有喔！我們跟北一、景美、松山、華江流音是友社。我們五校會一起辦很多活動，像是大迎、聖晚、寒訓。
此外下學期還有跟建中口技、北一流音的聯展，以及會由學弟妹們自己辦的建北景聯合小成。在這裡除了演出以外也能學到豐富的活動籌辦經驗喔！

# 流音有學長學弟制嗎？學長會不會很可怕？
我們社團沒有學長學弟制，學長們都很親切，學弟們完全不用擔心！

# 如果選社時錯失良機可以地社嗎？
可以呦！如果真的沒選上流音，我們的地社表單會出現在社帳精選。地社社員除了無法參與週五第五節的正式社課外，其餘的小社課與所有活動皆可自由參加，跟正社社員基本上一樣喔！
