# 社團活動
我們社團主要分成兩個部分，一是週五第五節的社課時間，我們會先唱一首詩歌，接著讀一篇「信息」，「信息」大部分是節錄聖經的話，再加上一些註解與解釋，讓大家可以更明白讀的內容
；有時候則是會看福音見證的影片，看看弟兄姊妹們是怎麼經歷主的。社團老師也會帶免費的飲料與點心來，一起度過一個愉快的下午~

# 小排聚會
除了社課時間以外，我們每周中午12：00~12：50也會有一次的「小排聚會」，每個年級的時間都不同，地點在我們的校外社辦—台北市召會第四十七聚會所，也就是在側門烤鴨店的樓上三樓
，除了也會唱詩歌、讀信息以外，還有免費的便當！所以完全不需要擔心午餐的問題，最重要的是，不需要是社員也能參加！只要你想來識神、認識聖經的，都歡迎大家來！

# 陪讀聖經
如果你對聖經非常有興趣，想知道神是怎麼跟我們說話的，我們每天放學後也有陪讀聖經的服務，一樣是到我們的社辦，大約4：10~5：00，除了讀經之外，弟兄們也會告訴我們這些經節的意思與背後意義，讓我們能明白這位奧秘的神

# 其他活動
當然，我們的活動也不只這些，我們每週也都還有主日聚會、運動相調，以及期末大家最期待的披薩相調(一起去社辦吃披薩)！對上面的活動有興趣的同學，不論你有沒有想要參加聖經真理研
究社，都歡迎大家來參加！可以加我的line或IG，開學時一起來享受神！
