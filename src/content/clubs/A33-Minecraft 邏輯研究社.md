# 上課方式
我們社團的上課方式相當特別：先觀看15-20分鐘的影片(本社親製)，剩下時間就會由各組上台，用社團提供的筆電進行實作(沒有遊戲不用擔心)，並由其他組別評分。累積分數最高的一組，期末會請飲料。有些上課時，則是進行Kahoot小測驗，一樣可以算分！在期末最後一堂課，則有我們的優良傳統－－披薩趴！

# 紅石中學邏輯
一起透過學習紅石機關背後的原理，理解邏輯，並將這種工程師思維內化吸收

# 想來點輕鬆的？
如果你只是想放輕鬆，麥研同樣歡迎你！在實作時間盡情發揮你的PVP、建築天賦；在期末披薩享受放鬆的感覺。

# 整合遊戲與IC設計
透過遊戲學習IC電路，展向強大的整合能力－－誰說我們只能水？展現給教授你的跨領域思維與學習能力，勝過書呆子！
