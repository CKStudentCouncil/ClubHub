# 圍棋社是甚麼東西
建中圍棋社的氛圍十分愜意，是非常自由且不受拘束的環境，有任何問題都可以向我們的幹部提問，同時活動也不會強制參加，想來再來就可以了。

# 專業指導
我們會邀請職業棋士王元均九段為社員們授課，從大局觀、中盤的戰術攻防到官子的細膩技巧，由大師親自拆解棋局、指點迷津。

# 小社課
我們除了每周五的社課外，也會辦一些自由參加的友校聯合活動。如果人數允許，也會不定期舉辦小社課。

# 幹部
我們的幹部人都很好，沒有學長學弟制，其中更有優秀的段位棋手。
