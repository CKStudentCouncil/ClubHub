# 軍武社是什麼？
軍武社是個由一群愛好軍事相關的建中生組成的社團。

# 軍武社在做什麼？
每週五都有一次社課，我們會有學長們上台報告（當然你想報告的話也可以向我們提出！），內容包括戰爭史、槍械結構、歷史上的奇葩武器、生存遊戲講解，如果有想聽的相關內容也可以找學長們預訂。
每個星期五下午都會在社辦舉行一次小社課，內容包括如何正確使用槍枝，瞄準射擊的技巧等等
# 會和其他學校的友社交流嗎？
會！每次都會有迎新、寒訓、暑訓。我們會和其他友社的同學們一起下場打生存遊戲。

# 沒有裝備也可以加入嗎？
可以！社團都有公用槍枝與裝備，只要有交社費就能夠無限借用槍枝以及相關耗材。
